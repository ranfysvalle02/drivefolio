m-stash

Go DLAC Gateway

Zero-boilerplate security proxy for MongoDB Atlas

1. What is m-stash?

m-stash is a high-speed, minimal Go security gateway proxy that sits between your client-side frontend (React, Vue, mobile, or vanilla JS) and MongoDB. It intercepts client requests, parses incoming JWTs, automatically injects owner-level access rules, and executes queries securely without exposing your database credentials.

2. Why does it matter? (The 2025 Problem)

In late 2025, MongoDB shut down App Services (Realm) and the Atlas Data API. Suddenly, frontend developers could no longer build direct serverless/JAMstack applications without coding, dockerizing, and maintaining massive Node/Express backends.

Typical Node/TS Gateway
• 150MB+ Docker footprint
• node_modules hell
• 100-200MB idle RAM usage
m-stash (Go Engine)
• ~15MB scratch container
• Zero dependencies
• ~15MB idle RAM on free tier

3. Declarative Access Control (DLAC)

Never trust client-supplied filters. m-stash inspects the token's authenticated claims.UID and automatically merges security policies using strict MongoDB $and clauses:

// Owner-scoped policy executed natively in Go:
"portfolios": {
"read": {"$or": [{"ownerId": "$auth.uid"}, {"isPublic": true}]},
"write": {"ownerId": "$auth.uid"}
}
